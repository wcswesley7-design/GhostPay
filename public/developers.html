Base URL

Produção 
https://ghostpaybank.com/v1

Endpoints principais

Operações essenciais do Pix.

POST /v1/charges

Cria cobrança Pix e retorna o ID e o link de pagamento.

GET /v1/charges/:id

Consulta status, QR Code e dados de pagamento.

GET /v1/balance

Saldo disponível e pendente do merchant.

POST /v1/withdrawals

Solicita saque por chave Pix (aprovação manual).

Criar cobrança Pix

Exemplo 
curl -X POST https://ghostpaybank.com/v1/charges \
  -H "Authorization: Bearer SEU_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"amount": 49.90, "description": "Pedido #1001"}'

Webhook (charge.paid)

Evento 
{
  "event": "charge.paid",
